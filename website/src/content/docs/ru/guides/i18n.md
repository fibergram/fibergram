```bash
pnpm add @fibergram/i18n
```

Effect-нативный аналог `@grammyjs/i18n` и middleware `I18n` из aiogram, поверх
[Fluent](https://projectfluent.org). Перевод делается через `t(key, vars)` с
**амбиентной локалью**: ни объекта контекста, ни проброса вниз по стеку вызовов.

## Собрать переводчик

`I18n.make` синхронный — парсинг Fluent чистый, — поэтому значение может строить
роуты ещё до существования любого `Layer`:

```ts
import { I18n } from "@fibergram/i18n"

const i18n = I18n.make({
  defaultLocale: "en",
  locales: {
    en: `
hello = Hello, { $name }!
menu-button = Menu
`,
    ru: `
hello = Привет, { $name }!
menu-button = Меню
`
  }
})
```

В настоящем боте источники приходят из файлов `.ftl`, прочитанных при старте, — в
собственном формате Fluent, с плюральными формами, селекторами и атрибутами
сообщений.

## Перевести

```ts
import { Chat } from "@fibergram/core"
import { Effect } from "effect"

const greet = Effect.gen(function* () {
  const text = yield* i18n.t("hello", { name: "Ада" })
  yield* Chat.reply(text)
})
```

`t` сам резолвит локаль и **ничего не добавляет в `R`**.

Либо доберитесь до переводчика через `R` свободными аксессорами, подключив
`I18n.layer(i18n)` на краю, — удобно, когда каталог собирается внутри графа слоёв:

```ts
import { I18n } from "@fibergram/i18n"

const greet = Effect.gen(function* () {
  const text = yield* I18n.t("hello", { name: "Ада" })
  return text
})
```

## Как выбирается локаль

Побеждает первое попадание:

1. явное переопределение `I18n.withLocale("ru")`,
2. предпочтение, сохранённое через `setLocale` в порт `DialogStore` (пропускается,
   если стора в контексте нет),
3. `languageCode` отправителя обрабатываемого апдейта,
4. `defaultLocale`.

Теги согласуются с загруженными локалями: точное совпадение → без учёта регистра →
первичный сабтег (`"pt-BR"` найдёт бандл `"pt"`) → дефолт.

```ts
// в любом хендлере — сохранить выбор отправителя
const toRussian = i18n.setLocale("ru")
```

Предпочтение хранится под kind `i18n:locale`, по умолчанию в области пользователя,
поэтому durable-[`DialogStore`](/ru/concepts/persistence/) делает его durable
бесплатно. Чтение оппортунистическое: `t` работает и вовсе без стора в контексте.

## Локализованный `hears`

Нажатия reply-клавиатуры приходят обычным локализованным текстом, и это неудобно:
пришлось бы сопоставлять со всеми переводами подписи. `i18n.hears` матчит перевод
ключа в **любой** загруженной локали и сообщает хендлеру, какая совпала:

```ts
import { Router } from "@fibergram/core"
import { Effect } from "effect"

const router = Router.make(
  i18n.hears("menu-button", (locale) => Effect.log(`меню открыто на ${locale}`))
)
```

Он несёт `kinds: ["message"]`, поэтому `Router.allowedUpdates` выводит подписку как
обычно.

## API

| Экспорт | Что это |
|---|---|
| `I18n.make(options)` | Синхронный конструктор над источниками `.ftl` по тегам локалей |
| `I18n.I18n` | Тег сервиса переводчика |
| `I18n.layer(service)` | `Layer<I18n>`, вносящий значение `make` в `R` |
| `I18n.t(key, vars?)` | Свободный аксессор: форматировать в текущей локали |
| `I18n.locale` | Свободный аксессор: согласованная текущая локаль |
| `I18n.setLocale(tag)` | Свободный аксессор: сохранить предпочтение |
| `I18n.withLocale(tag)` | Ограничить явное переопределение областью эффекта |
| `I18n.currentLocale` | Сама амбиентная ссылка переопределения |

На значении `make`: `t`, `locale`, `setLocale`, `translate(locale, key, vars?)`
(чистый поиск по локали, возвращает `Option<string>`), `hears`, плюс `locales` и
`defaultLocale`.

## Модель отказов

- **Отсутствующий ключ** откатывается к дефолтному бандлу. Отсутствие в *обоих* —
  ошибка программиста, и она падает defect'ом: пользователь никогда не должен
  увидеть сырой идентификатор сообщения.
- **Отсутствующая переменная** не фатальна: Fluent отрисует свой плейсхолдер
  `{$name}`.
- `useIsolating` по умолчанию `false`, поэтому отформатированный текст чисто
  проходит через Telegram, а `hears` может точно совпасть. (Bidi-изоляторы Fluent
  невидимы, но сломали бы и то, и другое.)

## В связке с меню

Подписи меню могут быть `Effect` — а локализованная подпись именно ею и является:

```ts
Menu.make("main", { text: "…" }).text("lang", I18n.t("menu-button"), handler)
```

Подпись перерисовывается для каждого пользователя в его локали без дополнительной
машинерии. [Пример restaurant-booking](https://github.com/fibergram/fibergram/tree/main/examples/restaurant-booking)
делает так для полноценного двуязычного меню.
